Flash Tag Protocol
Credential Disclosure System for Autonomous AI Agent Networks
⚿ Patent Pending · App. 64/040,921

Enables AI agents to disclose credentials selectively and with operator consent. An agent reveals only what the receiving party is permitted to see, based on pre-approved disclosure rules set by the human operator — not by the agent itself. This separates credential disclosure authority from the agent's execution context, making credential exposure a governance-controlled event rather than an autonomous agent decision.

Formal USPTO Title
Flash Tag Protocol: A Privacy-Preserving, Operator-Governed, Consent-Based Credential Disclosure System for Autonomous AI Agent Networks
Filed: April 16, 2026 · App. No. 64/040,921 Protocol detail → Now accepting waitlist signups — commercial launch coming Q2 2026.
AATS — Agentic Accountability Trust Score
Behavioral Reputation System for Autonomous AI Agents
⚿ Patent Pending · App. 64/043,587 ⬡ Open Standard

A behavioral reputation system for AI agents. Scores are computed from verifiable on-chain behavior, embedded in portable cryptographic credentials, and anchored to a tamper-evident log. Agents earn trust over time; anomalous behavior is detected and reflected in the score automatically. The score is a multi-dimensional composite across five independently weighted dimensions — delivery track record, behavioral consistency, operating history, financial reliability, and verified identity.

Formal USPTO Title
System and Method for Generating and Embedding Multi-Dimensional Behavioral Accountability Trust Scores in Portable Verifiable Credentials for Autonomous AI Agents
Filed: April 19, 2026 · App. No. 64/043,587 Protocol detail → Now accepting waitlist signups — commercial launch coming Q2 2026.
CRP — Context Recall Protocol
Immutable AI Agent Memory Recall Attestation
⚿ Patent Pending · App. 64/043,598

Ensures that every decision an AI agent makes can be traced back to the exact memory context it had when the decision was made. Memory states are cryptographically hashed and anchored before use — making recall immutable and independently verifiable. The protocol prevents retroactive modification of memory states and creates a cryptographic binding between the agent's active memory at decision time and the decision record itself.

Formal USPTO Title
Verifiable Context Recall Protocol: A Cryptographic Hash-Anchored System for Immutable AI Agent Memory Recall Attestation
Filed: April 19, 2026 · App. No. 64/043,598 Protocol detail → Now accepting waitlist signups — commercial launch coming Q2 2026.
ACP — Attribution Chain Protocol
Cryptographic Chain of Custody for AI Agent Hierarchies
⚿ Patent Pending · App. 64/043,613

Creates a cryptographic chain of custody for every AI agent spawn event. When one agent creates another, the parent-child relationship, the scope of delegated authority, and the human operator responsible are all recorded and anchored to a tamper-evident log before the child agent executes its first instruction. The pre-execution blocking gate makes ledger anchoring a structural dependency in the process graph — not an optional audit step. This means attribution is mandatory at spawn time, not reconstructable after the fact.

Formal USPTO Title
System and Method for Generating, Anchoring, and Verifying Cryptographic Attribution Chain Records for Hierarchical Autonomous AI Agent Orchestration
Filed: April 19, 2026 · App. No. 64/043,613 Protocol detail → Now accepting waitlist signups — commercial launch coming Q2 2026.
OGPP — Operator Governance Propagation Protocol
Human Governance Constraint Enforcement Across AI Agent Hierarchies
⚿ Patent Pending · App. 64/043,620

Ensures that human operator governance constraints propagate unchanged through every level of an AI agent hierarchy. A mandatory constraint set by a human operator at the top of a hierarchy is cryptographically encoded and cannot be overridden, softened, or bypassed by any agent in the chain — including agents that spawn further sub-agents. Local Enforcement Gates intercept every Discrete Action Proposal before it produces external effects. Constraints are verified at each level before execution proceeds.

Formal USPTO Title
System and Method for Cryptographic Encoding, Hierarchical Propagation, and Pre-Execution Enforcement of Human Operator Governance Constraints in Autonomous AI Agent Networks
Filed: April 19, 2026 · App. No. 64/043,620 Protocol detail → Now accepting waitlist signups — commercial launch coming Q2 2026.
AICP — AI Commerce Protocol
Transaction Engine for Autonomous AI Agent Commerce
⚿ Patent Pending · App. 64/043,611

The transaction engine for autonomous AI agent commerce. Enables AI agents to commission work from other agents using a payment escrow cryptographically bound to the exact task specification before work begins. An Autonomous Verification Gate evaluates delivery deterministically against pre-committed acceptance criteria — without human approval at any step. A four-phase Autonomous Dispute Resolution Protocol resolves disputes computationally before escalating to human arbitration. The AICP ensures that payment and task specification are hash-locked to each other at contract formation, making post-hoc modification impossible.

Formal USPTO Title
System and Method for Hash-Bound Task Specification Escrow, Completion Attestation, and Autonomous Dispute Resolution in Autonomous AI Agent Commerce
Filed: April 19, 2026 · App. No. 64/043,611 Protocol detail → Now accepting waitlist signups — commercial launch coming Q2 2026.
