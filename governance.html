How It Works

Define. Propagate. Enforce.

Three stages. No human can review every spawn at machine speed — so the protocol does it for them, cryptographically.

01 — Define

Constraints in machine-evaluable form

The operator signs a Governance Constraint Record containing every constraint — prohibited tools, output limits, resource caps, delegation rules. Mandatory constraints are marked and hash-locked. The record is anchored to the ledger before any agent acts.

02 — Propagate

Ledger record at every spawn

When any agent spawns a sub-agent, a Governance Inheritance Binding is generated and anchored to the ledger before the sub-agent executes. The mandatory constraint hash travels unchanged through the entire hierarchy. Any relaxation breaks it — and any third party can detect it.

03 — Enforce

Every action intercepted at the boundary

The Local Enforcement Gate intercepts every tool call, API request, and message before external effects are produced. Deterministic rule-matching — no LLM inference. Violations are blocked in real time and logged as tamper-evident events.

Questions

Common questions.

Governance drift is the silent relaxation of operator constraints as they pass through AI agent hierarchies. When agents spawn sub-agents at machine speed — no human reviews each delegation. Intermediate agents can narrow or drop mandatory rules with no record. OGPP makes this technically impossible and immediately detectable by anyone with ledger access.
The LEG intercepts every discrete action proposal — tool calls, API requests, file writes, messages — before external effects are produced. It evaluates each against the agent's constraint set using deterministic rule-matching. No LLM inference. Violations are blocked in real time and permanently logged.
Every Governance Inheritance Binding contains a mandatory_constraints_hash that must match the root operator's hash exactly, at any depth. Any party with ledger access can retrieve any GIB and compare hashes. No access to internal systems, no platform cooperation required.
